# Training Language Models For Sentiment Classification with Learned Embeddings

![text_embeddings](https://miro.medium.com/v2/resize:fit:2000/format:webp/1*0OVy_qF0NLJOyUnfz8lRzg.jpeg)

#### ``Objectives``
1. Train a sentiment classifier for movie reviews using movie review data from IMDB
2. Improve generalization performance using **one-hot encoding** and **featuer engineering** techniques
3. Experiment with **text embeddings** learned from the trained model and **scale up** the model to improve final results

#### ``Data``
Our data includes 50,000 movie reviews on IMDB. The data comes pre-segmented into train and test splits.
